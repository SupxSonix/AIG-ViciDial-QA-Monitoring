# One-call manager review links

Open Edit notes, expand Manager review link, and choose Create review link. Confirm the single-call access, then copy the link for the manager. Creation verifies the recording and downloads a private MP3 copy; large recordings can take time. The link expires after 24 hours, permits repeated listening until a single response is submitted, and can be revoked from the creation panel. It continues to work after the creator logs out or the service restarts. The token is in the URL fragment, outside server access-log URLs. Treat it as access to this recording.

The manager enters Approved by, selects Valid / Invalid / Not sure, and may add notes. The name is self-reported, not a verified login identity. After submission the link stops returning the recording or accepting responses. Submission saves a response, not an upstream QA change. The creator opens the same call's Edit notes, chooses Load manager responses, selects Use this response in notes, and saves the note through the normal authenticated ViciDial flow. Responses are visible only to the creating supervisor account.

The Node preview binds REVIEW_LINKS to private storage/review-links (override QA_REVIEW_LINK_DIR). Files contain only the selected recording snapshot, audio and response. Credentials are never written there. Keep this directory writable by the service user, private, and included in protected backups. Source control excludes storage/. Review files are removed after 30 days when another review link is created; link access expires independently after 24 hours. Backups follow their own retention policy. Cloudflare Worker deployments need a compatible REVIEW_LINKS service binding; without it the feature returns an unavailable message.

Rebuild and restart after deployment. npm test includes ownership verification, opaque tokens, logout/restart persistence, audio isolation, expiry, revocation, concurrent double-submit rejection, supervisor response isolation and review-page CSP checks.
